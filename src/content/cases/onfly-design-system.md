## Context

Onfly needed a single source of truth to keep its web platform consistent as the product and team grew.

## What I did

- Structured the technical foundation with **611 design tokens** (primitive, semantic, component-level), customizing Quasar (Vue) components to Onfly's identity.
- Designed a library of **143 components / 2,490 variants** following Atomic Design.
- Ran a full audit and an accessibility analysis that set a **23% WCAG baseline**, then prioritized remediation.
- Built AI agents for the DS ecosystem (JSON→SCSS tokens, component generation from Figma specs).

## Results

Adopted by **5 designers and ~40 developers**, with Design Ops processes for governance and continuous evolution.
